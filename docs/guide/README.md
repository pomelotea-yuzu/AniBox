# guide/ · 快速开始

> 面向使用者。当前 AniBox 只发布 Windows 便携版，没有安装器。

## 拿到包之后

1. 解压便携 zip 到任意目录（**不要在压缩包里直接运行**，便携版会在同目录生成 `data/`）。
2. 双击 `AniBox.exe`。
3. 首次启动先添加番剧根目录（设置 → 库 → 扫描根目录），等扫描跑完。
4. 注意：`data/` 是业务数据（库、进度、索引缓存），**升级时保留它**，删掉等于重置。

## 播放

| 操作 | 快捷键 |
|---|---|
| 播放/暂停 | `Space` |
| 音量 / 静音 | `↑` `↓` / `M` |
| 字幕开关 / 切轨 | `V` / 长按 `V` |
| 音轨切换 | `A` |
| 截图 | `S` |
| 播放模式（单集/连播/循环） | `L` |
| AB 循环打点 | `[` / `]` |
| 跳 OP/ED | **连按 3 次右键**（600 ms 内），默认跳 90 秒 |
| 帮助 | `?` 或 `Esc` 关闭 |

## 常见问题

- **画面黑但有声音**：libmpv 初始化失败，应用应自动回退 HTML5；若仍黑屏，把 `data/` 下的日志留档反馈。
- **没封面 / 没简介**：先确认内置索引是否在位（新番时间表与刮削都依赖它），无索引时在线源大概率也拿不到。
- **HEVC 播不了**：回退到 HTML5 后受 Chromium 解码能力限制，属已知边界。

已知限制与欠账以 [`../knowledge/debt.md`](../knowledge/debt.md) 为准，本文不重复。
