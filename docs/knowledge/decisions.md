# 关键决策速查

> 格式：决定 / 理由 / 代价 / 推翻条件。只收**已经定下并影响多条链路**的决策；一次性的实现选择不进来。

## D1 播放：libmpv 内嵌为默认，HTML5 与 mpv.exe 窗口作回退（2026-09）

- **理由**：HTML5 播不了 HEVC/10bit/多音轨，也拿不到精确的帧信息；mpv.exe 独立窗口无法做自定义控件与封面墙联动。libmpv + Render API 能同时满足画面与交互。
- **代价**：koffi FFI、SW 渲染的一堆坑（见 `runtime-probe.md`），以及每台机器的 DLL 分发。
- **推翻条件**：Electron 官方支持硬解 HEVC 多音轨，或 libmpv 崩到无法维持。

## D2 元数据：本地 Bangumi 官方 dump 建索引，在线仅回退（2026-09-07）

- **理由**：2026-09 实测 AniList 403、Bangumi API/CDN 超时、萌娘 API 关停、TMDB 与 B 站全超时——在线链路整体不可用；dump 一次生成可长期离线查表。
- **代价**：发布包 +10 MB（内置 `core.json.gz` 3.35 MB + `summary.json.gz` 6.85 MB），季度需手动更新；匹配靠标题归一化，季号对齐弱。
- **推翻条件**：出现稳定、可商用、免鉴权的在线数据源，且延迟可接受。

## D3 封面：yuc.wiki 季度页 + 本地缓存 + `anibox://cover`（2026-09-07）

- **理由**：dump 条目没有封面字段、没有外站 ID，在线图片源全部失效；yuc.wiki 按季度列出新番且有中文标题可匹配。本地抽帧方案被否决（丑且慢，不代表作品）。
- **代价**：只覆盖 2020 年之后的番；B 站 CDN 有 Referer 防盗链，必须走本地协议中转。
- **推翻条件**：出现带封面的离线数据集。

## D4 数据存储：纯 JSON store（2026-08）

- **理由**：`better-sqlite3` 与 Electron 33 的 ABI/N-API 冲突且沙箱无法重编译；数据量（数千条目）用不着数据库。
- **代价**：全量读写、并发写需自己串行化；大库时 IO 抖动。
- **推翻条件**：条目上到十万级，或需要复杂查询。

## D5 分发：手动打包流水，不用 electron-builder 直接出包（2026-09-08）

- **理由**：本机沙箱跑不通 electron-builder（下载与权限双重限制）。流水 = `mk-stage` 自举 stage → node 直调 `@electron/asar` → 覆盖 `win-unpacked` → `pack-zip`。
- **代价**：脚本与版本号耦合（`mk-stage121.py`/`pack-zip-123.py` 名字里带版本），每次发版要复制改名；中间产物需手工清理。
- **推翻条件**：打包机具备完整 electron-builder 条件（干净环境 + 稳定网络）。

## D6 画质：Anime4K 三预设 + 后期滤镜；跳过 24→60 插帧（2026-09）

- **理由**：插帧在动画上伪影明显、成本高（RTX 3060 6GB 余量有限），收益不如去带/AA/色彩；Anime4K 有三个成熟预设可直接给用户选。
- **代价**：不与 RIFE 类方案站在同一起点；"更顺滑"这一卖点放弃。
- **推翻条件**：RIFE ncnn 在 6 GB 显存上能稳定实时且伪影可接受（要 A/B 证据，不是感觉）。

## D7 仓库治理：采用 Layress 整套范式 + OpenSpec（2026-11-22）

- **理由**：旧仓靠人肉记忆维护，坑散落在各工具的本机记忆里，clone 的人接不上手；Layress 已经把"接手入口 + 目录归属 + 门禁 + 经验库 + 产物隔离"做成一套。
- **代价**：短期内要维护门禁脚本与文档纪律；新增目录必须登记。
- **推翻条件**：治理成本明显高于收益（例如单人维护期已经无暇跑门禁）——那就降级而不是废弃。

## D8 仓库根上移到 `D:\AniBox`，应用进 `apps/desktop`（2026-11-22）

- **理由**：旧根 `D:\AniBox` 混着便携包、`data/`、`mpv-dev`、修复报告，`anibox/` 才是仓库；治理需要一个干净根。应用整包搬进 `apps/desktop` 后，`__dirname/../..` 的相对关系原样保留（`resources/`、`mpv.exe`、`libmpv-2.dll` 全部跟着走），无需改代码。
- **代价**：`process.cwd()` 相关的 dev 回退路径（`yuc-covers/`、`anibox-index/`）跟着 package 走；所有命令要在 `apps/desktop` 或经根委托脚本执行。
- **推翻条件**：真拆出 `packages/*` 需要不同的物理布局（届时走 change，不靠手工搬）。
