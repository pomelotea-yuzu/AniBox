# 架构不变量

> **这里的每一条都不许重开。** 改写前先读"不成立时的后果"；要推翻必须走 OpenSpec change 并同步
> `openspec/config.yaml` 的 I 编号清单与 [`decisions.md`](decisions.md)。
> 条目来源：`runtime-probe.md` / `engineering.md` 里第二次踩到的坑，或已被实机证伪的路线。

| 编号 | 不变量 | 不成立时的后果 |
|---|---|---|
| I1 | 播放引擎回退链完整且对用户可见：libmpv 内嵌 → HTML5 video → mpv.exe 管道窗口 | 单点失败变成黑屏且无提示，用户以为"文件坏了" |
| I2 | SW 渲染下禁止 `mpv_command`（cycle/stop 等）；控制一律走 `setProperty` 适配层 | 原生崩溃，进程直接消失，日志里没有 JS 堆栈 |
| I3 | EOF 只认 `keep-open=yes` + 轮询 `eof-reached`；不要等 `END_FILE` | 播放结束无事件，UI 永久停在播放中，续播进度写不进去 |
| I4 | 帧像素必须经 WebGL 纹理上屏，shader 强制 `alpha = 1` | 画面全黑但音频正常（2D canvas 或预乘 alpha 的典型症状） |
| I5 | 元数据以本地 dump 索引优先，在线链路只作回退；网络全灭不得阻塞扫库与播放 | 断网时整个应用不可用（2026-09 全在线源失效时正是这个形态） |
| I6 | 封面只走本地缓存 + `anibox://cover`；渲染进程不直连 B 站 CDN | 带 Referer 的请求 403、封面全裂；即便通了也把网络依赖塞进了最核心的浏览体验 |
| I7 | 便携优先：业务数据跟随产品目录——便携版 `<软件目录>/data`、开发态仓库根 `.anibox/`，拷走即迁移 | 用户换机器/换盘后库和进度全丢；"便携版"名不副实 |
| I8 | 打包路径必须显式：stage 目录、`dist/`、旧产物不得互相误取 | 打进旧 stage 的产物，发出去的包是上一版 |
| I9 | 机器 PASS ≠ 人工通过：画面、字幕、音轨、seek 类判定必须实机复核 | 自动化全绿而用户一上手就发现字幕不显示 |
| I10 | 索引、模型、二进制不入库；仓库只留生成脚本与 allowlist 理由 | 仓库膨胀到无法 clone，且大文件进了历史删不干净 |
| I11 | 单一数据源：IPC 按域拆在 `src/main/ipc/`，控件定义只在 `controlsData.ts` | 同一常量两处维护，改一处漏一处，调试时互相甩锅 |

## 已知的"部分成立"

- **I7 的边界是"安装版"**：NSIS 安装版仍用 Electron 默认 `userData`（系统用户目录）——这是有意的，
  因为安装版没有"产品目录"这个可携带的容器。开发态与便携版都已重定向，解析结果会打印
  `[AniBox] 数据目录（…）= <路径>`。UI 里展示数据目录仍欠着，见 [`debt.md`](debt.md)。
- **I5 的弱点是季号对齐**：见 `debt.md` 的"XX 第二季命中第一季"条目。
